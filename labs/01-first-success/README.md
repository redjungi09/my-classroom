# 01 · 첫 성공

수업 첫날 내 컴퓨터에서 실행했던 16줄 서버를 다시 실행합니다. 코드는 그때와 같습니다. 달라지는 것은 **서버가 실행되는 곳**과 **실행하는 방법**입니다.

코드는 [server.mjs](server.mjs) 하나입니다. 연결을 받고, 첫 데이터가 도착하면 고정된 응답을 보내고 연결을 끝냅니다. 외부 패키지가 없어 설치 명령은 필요 없습니다.

## 화면에서 실행하기

내 교실 앱의 **네트워크 → 01 · 첫 성공** 화면에서 합니다.

1. **서버 켜기**를 누릅니다. “서버 켜짐 · 포트 8080”으로 바뀝니다. 서버는 요청이 올 때까지 기다리기만 합니다.
2. **요청 보내기**를 누릅니다. 응답 원문에 `HTTP/1.0 200 OK`로 시작하는 글자가 나오고, 그 아래에 브라우저가 그린 화면이 나옵니다.
3. 서버 터미널 출력에는 서버가 받은 요청이 찍힙니다. 내가 보낸 글자와 같은지 봅니다.

## 내 문장으로 바꾸기

1. 코드 칸의 `Hello!`를 `Hello, Mina!`처럼 영문으로 바꾸고 **파일에 저장**을 누릅니다.
2. **요청 보내기**를 누릅니다. 응답이 바뀌었나요?
3. **서버 껐다 켜기**를 누른 뒤 **요청 보내기**를 누릅니다. 이번에는 어떤가요?

저장만으로는 왜 바뀌지 않았는지 내 말로 적어 봅니다.

## 더 해 보기

- **서버 끄기**를 누른 뒤 **요청 보내기**를 누르면 어떤 글자가 나오나요? 그 뜻은 무엇일까요?
- 요청 칸의 `GET / HTTP/1.0`을 `HELLO`로 바꿔 보내 봅니다. 응답이 달라지나요? 코드의 어느 부분 때문일까요?

## 터미널에서 실행하기

화면의 서버 켜기 버튼은 터미널에 아래 명령을 입력하는 것과 같은 일을 합니다. 화면에서 켜 둔 서버가 있으면 먼저 끕니다. 같은 포트는 한 프로그램만 쓸 수 있습니다.

```sh
cd labs/01-first-success
npm start
```

Codespace에서는 터미널 옆 **PORTS** 탭의 `8080` 줄에서 지구본 모양(Open in Browser)을 누르면 브라우저로도 열 수 있습니다.

## 예전과 무엇이 달라졌나요

- 예전에는 브라우저 주소창에 주소를 넣었습니다. 지금 “요청 보내기”는 누가 서버에 연결하는 것일까요? 내 브라우저일까요, 내 교실 앱의 서버일까요?
- Codespace에서 실행했다면, 이 16줄 서버는 지금 어느 컴퓨터에서 돌고 있나요?

## 이 예제가 하지 않는 것

요청 내용을 해석하지 않아 무엇을 보내도 같은 응답을 보냅니다. `data` 한 번이 HTTP 요청 하나와 같다는 뜻은 아닙니다. 한글과 UTF-8은 이 예제에서 다루지 않습니다.
